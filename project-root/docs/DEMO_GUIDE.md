# Демо-режим ДокПоток IRIS — руководство для презентации заказчику

Демо-режим предназначен для показа возможностей системы без доступа к реальным
данным. Все данные вымышленные, чувствительные функции (экспорт, внешние
интеграции) отключены, над интерфейсом отображается баннер «Демо-режим».

## Запуск

```bash
# Backend (из project-root/backend)
set MODE=demo   # Windows cmd; в bash: export MODE=demo
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

При старте в режиме `demo` база автоматически заполняется вымышленным набором
данных (если демо-пользователь ещё не создан). Повторный запуск данные не дублирует.

Также доступен готовый скрипт `scripts/СТАРТ_ДЕМО.bat` (backend + frontend + браузер).

## Вход

На странице логина появляется зелёная кнопка «Демо-режим» — она входит под
демо-учётной записью. Либо вручную:

- **Логин:** `demo@iris.local`
- **Пароль:** `demo1234`

Дополнительные вымышленные пользователи: `engineer@iris.local` (инженер),
`manager@iris.local` (руководитель проекта) — пароль тот же `demo1234`.

## Демо-сценарий (15–20 минут)

1. **Вход и дашборд.** Показать баннер «Демо-режим», стратегическую сводку,
   виджеты рисков, загрузку по отделам, замечания.
2. **Портфель заказов.** Открыть проект `DEMO-001` («Жилой комплекс “Северный”»),
   показать структуру проекта, команду, сроки.
3. **Документация.** Открыть документ, показать просмотрщик (PDF/Word/Excel),
   версии и статусы согласования.
4. **Замечания.** Показать канбан/таблицу замечаний, приоритеты, переходы статусов.
5. **Аналитика.** Графики загрузки, учёт времени, геймификация (очки/XP).
6. **Ограничения.** Показать, что кнопки «Экспорт» отключены с подсказкой
   «Недоступно в демо-режиме», а AI-ассистент возвращает вежливый отказ —
   это сделано намеренно для защиты данных.

## Что включено / выключено в демо

| Функция | Демо-режим |
|---|---|
| Просмотр всех разделов | ✅ |
| Создание/редактирование проектов, документов, замечаний, задач | ✅ |
| WebSocket совместная работа | ✅ |
| Экспорт (архив, замечания, 1С) | ❌ 403 |
| AI-ассистент и внешние интеграции (OpenAI, 1С) | ❌ 403 |
| Кнопка «Сообщить о проблеме» | ❌ скрыта |
| Логи | только консоль, без файлов |

## Частые вопросы заказчика

- **«Это реальные данные?»** — нет, все компании, люди и проекты вымышленные
  (заказчик ООО «Демонстрация», проекты DEMO-001..003).
- **«Как попадут наши данные?»** — см. `docs/DATA_LOADING.md`: рабочий режим
  с реальными пользователями и документами.
- **«Как сбросить демо?»** — удалить файл БД SQLite (`iris_dev.db`) и перезапустить
  backend: демо-набор будет создан заново.

## Проверка перед презентацией

```bash
cd project-root/backend
python scripts/smoke_modes.py --base-url http://127.0.0.1:8000 --mode demo
```

Все проверки должны быть `[OK]`.
