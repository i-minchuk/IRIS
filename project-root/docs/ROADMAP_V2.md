### Последние изменения (MVP 4.4.0)
- ✅ Электронное подписание workflow — hash-based SHA256 (`WorkflowSignature`), endpoint `POST /workflows/steps/{step_id}/sign`, аудит IP + user agent
- ✅ Email уведомления в workflow — 7 шаблонов (started, assigned, approved, rejected, rejected_return, delegated, completed), интегрированы в `WorkflowService`
- ✅ Валидация форм — DocumentCreate (real-time blur, required, maxLength), AdminPage (проверка имени, toast уведомления)
- ✅ Глобальные hotkeys — Ctrl+K поиск, Ctrl+S submit форм, Escape закрытие модалок
- ✅ WorkflowPanel UI — кнопки подписания, согласования, отказа, делегирования
- ✅ Исправлены ошибки сборки frontend (TypeScript типы, импорты API client)
- ✅ Time Tracking frontend module (таймер, сессии, аналитика)
- ✅ Устранение дерганий Dashboard: часы вынесены в изолированный компонент, автообновление данных — silent
- ✅ Глобальное увеличение шрифта (`font-size: 17px`) и белый фон приложения
- ✅ Унификация layout страниц: убраны `max-w-* mx-auto`, контент прижат к левому краю
- ✅ Убраны дублирующие иконки и заголовки со страниц
