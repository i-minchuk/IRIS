# Данные: демо-набор и загрузка реальных данных

## Демо-данные (режим demo)

При старте backend с `MODE=demo` и включённом `features.demo_data_seed`
выполняется `app/db/demo_seed.py`: если пользователя `demo@iris.local` нет,
создаётся фиксированный вымышленный набор:

- **Пользователи** (пароль у всех `demo1234`):
  - `demo@iris.local` — администратор (Деми Демидов);
  - `engineer@iris.local` — инженер (Инна Инженерова);
  - `manager@iris.local` — руководитель проекта (Марк Менеджеров).
- **Проекты:** DEMO-001 «Жилой комплекс “Северный”», DEMO-002 «Бизнес-центр “Меридиан”», DEMO-003 «Школа на 1200 мест». Заказчик — ООО «Демонстрация» (вымышленное).
- **Документы:** 3 документа в разных статусах согласования.
- **Замечания:** 3 (разные приоритеты и статусы).
- **Задачи:** 4 по проектам.
- **Тендеры:** 2.

Сид идемпотентен: маркер — наличие `demo@iris.local`, повторный запуск ничего
не дублирует. Сброс демо: удалить файл БД SQLite и перезапустить backend.

Ручной запуск сида (без рестарта):

```bash
cd project-root/backend
python -c "import asyncio; from app.db.demo_seed import seed_demo_data; asyncio.run(seed_demo_data())"
```

## Загрузка реальных данных (режим prod)

Автосид в prod отключён. Рекомендуемый порядок наполнения через UI
(тот же порядок применим и для API/скриптов):

1. **Пользователи.** Первый администратор — через `/register` или сид-скрипт;
   остальные — через раздел «Администрирование» (роли: admin, manager, engineer, viewer).
2. **Проекты.** Раздел «Портфель заказов» → «Новый проект»: код, название,
   заказчик, сроки, команда.
3. **Документы.** Раздел «Документация» → загрузка файлов (PDF, DOCX, XLSX, DWG),
   заполнение карточек (шифр, стадия, версия).
4. **Замечания и задачи.** Создаются в карточках документов/проектов либо
   импортируются вручную.
5. **Справочники.** Раздел «Справочники» — переменные, типы документов.

### Массовая загрузка через API

Все сущности доступны через REST (`/api/v1/...`, токен администратора).
Пример создания проекта:

```bash
curl -X POST http://localhost:8000/api/v1/projects \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"code": "PRJ-001", "name": "Реальный проект", "customer": "ООО Заказчик"}'
```

### Правила безопасности

- Никогда не переносить реальные данные в базу, используемую для demo.
- Демо-пользователи (`*@iris.local`) не должны существовать в prod-базе.
- Перед загрузкой большого объёма файлов проверить `IRIS_STORAGE_ROOT` и место на диске.
