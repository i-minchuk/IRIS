# Чек-лист регрессионного тестирования

Полный прогон занимает ~10 минут. Порядок: сверху вниз по списку.
Логин для прогона: `admin` / `admin321` (тестовый контур).

Окружение перед стартом:

- [ ] Бэкенд отвечает: `GET http://localhost:8000/health` → 200
- [ ] Фронтенд отвечает: `http://localhost:5173` → страница входа
- [ ] Консоль браузера открыта (F12) — во время прогона не должно быть красных ошибок

---

## 1. Вход и сессия

- [ ] Страница `/login` открывается, поля логина/пароля и кнопка «Войти» активны
- [ ] Вход под админом успешен → редирект на `/dashboard`
- [ ] **Консоль чистая**: на странице входа без токена нет 401 `/auth/me`
- [ ] Обновление страницы (F5) на любой вкладке сохраняет сессию

## 2. Панель аналитики (`/dashboard`)

- [ ] Все секции отрисованы: финансовая сводка, тендерная воронка, структура портфеля,
      динамика выручки, топ проектов, «Учёт времени и качество работы»,
      загрузка по отделам, замечания, лидерборд, календарь
- [ ] Периоды «Сегодня / Неделя / Месяц / Квартал» переключаются, данные обновляются
- [ ] Кнопка «Обновить данные» (круглая стрелка) перезагружает виджеты
- [ ] Тумблер автообновления вкл/выкл меняет состояние
- [ ] Меню интервала (30 с / 1 мин / 5 мин) открывается и применяется
- [ ] «Все тендеры» → переход на `/portfolio?tab=tenders`
- [ ] Мини-графики KPI без ошибок `NaN` в консоли
- [ ] Пустые виджеты показывают заглушки, а не пустоту

## 3. Документация (`/documents`)

- [ ] Дерево проектов слева: проекты раскрываются, документы видны
- [ ] Клик по документу открывает карточку с предпросмотром
- [ ] Двойной клик по проекту/документу → переименование
- [ ] **Правый клик по проекту**: Переименовать / Вставить документ /
      Переместить в архив / Удалить — все пункты работают
- [ ] **Правый клик по документу**: Переименовать / Копировать / Вырезать /
      Переместить в проект… / Исключить из работы — все пункты работают
- [ ] Правый клик по пустому месту списка → «Вставить»
- [ ] Ctrl+C / Ctrl+V копируют и вставляют документ между проектами
- [ ] Диалоги «Исключить документ» и «Удалить проект» открываются, имеют поле причины
- [ ] Вкладка «Задачи» переключается
- [ ] Вырезанный документ полупрозрачный, после вставки подсветка снимается

## 4. Портфель (`/portfolio`)

- [ ] Главные вкладки переключаются: Тендеры / Договоры / Проекты / Закупка-МТО / Архив
- [ ] Подвкладки тендеров: Заказчики / Тендеры / Типовые решения / Шаблоны
- [ ] Подвкладки закупки: Заявки / Счета / Заказы / Поставщики / Процесс МТО
- [ ] **Вкладка «Архив»**: архивные проекты с датой и причиной,
      кнопка «Вернуть в работу» возвращает проект

## 5. Производственный контроль (`/production`)

- [ ] Список проектов в производстве отображается

## 8. Отчёты (`/reports`)

## 11. Профиль (`/profile`)

- [ ] Основная информация отображается

## 12. Уведомления (`/notifications`)

## 13. Семантический поиск (`/ai-search`)

- [ ] Форма поиска отображается, запрос выполняется (или честная ошибка об AI-ключе)
