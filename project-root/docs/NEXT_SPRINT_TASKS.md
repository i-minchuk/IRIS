## 📋 Задачи на следующий спринт

### 🔴 Критичный приоритет

#### K1. Исправить несоответствие типов в archive моделях
**Описание:** В `app/models/archive.py` поле `author_id` объявлено как `UUID`, но ссылается на `users.id` типа `Integer`. Миграция уже исправлена вручную, но модель остаётся некорректной.
**Критерии приёмки:**
- [ ] `author_id` в `ArchiveEntry` изменён на `Integer`
- [ ] Пересоздана миграция или создана новая корректирующая
- [ ] `alembic upgrade head` проходит без ошибок
**Оценка:** 2 часа

#### K2. Исправить ProtectedRoute — добавить реальную проверку авторизации
**Описание:** Сейчас `ProtectedRoute` пропускает всех пользователей (pass-through `<Outlet />`). Нужно добавить проверку наличия токена и валидности сессии.
**Критерии приёмки:**
- [ ] Проверка `access_token` в localStorage
- [ ] При отсутствии токена — редирект на `/login`
- [ ] При 401 от API — logout и редирект
- [ ] Проверка ролей для `/admin` сохранена
**Оценка:** 4 часа

#### K3. Backend `/auth/me` должен возвращать поле `role`
**Описание:** Frontend ожидает поле `role` в ответе `/api/v1/auth/me`, но backend его не возвращает. Сейчас используется fallback `'engineer'`.
**Критерии приёмки:**
- [ ] В схеме `UserResponse` добавлено поле `role: str`
- [ ] Endpoint `/auth/me` возвращает `role` из БД
- [ ] Frontend убран fallback, используется реальная роль
**Оценка:** 2 часа
